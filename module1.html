What is Data Science?

Data Science is an interdisciplinary field that uses statistics, mathematics, programming and machine learning to extract useful information from data.

Why is Data Science Important?

  • Helps organizations make better decisions.
  • Finds useful patterns from large datasets.
  • Supports prediction and forecasting.
  • Helps businesses understand customers.
  • Used in Artificial Intelligence and Machine Learning.

Applications of Data Science

  • Healthcare
  • Banking and Finance
  • E-Commerce
  • Education
  • Social Media
  • Cyber Security
  • Transportation

Python Programming

Python is a high-level, interpreted and general-purpose programming language. It is widely used in Data Science because of its simple syntax and powerful libraries.

Simple Python Program

name = "Navaneeth"
age = 20

print("Name:", name)
print("Age:", age)

Python Variables & Data Types

A variable is a name used to store a value in a program. Python automatically determines the data type.

  • int → Integer values
  • float → Decimal values
  • str → Text
  • bool → True or False
  • list → Collection of values
  • tuple → Ordered immutable collection
  • set → Unordered unique values
  • dict → Key-value pairs
age = 20
price = 99.5
name = "Navaneeth"
passed = True

print(age)
print(price)
print(name)
print(passed)

Control Statements

If-Else Statement

marks = 75

if marks >= 40:
    print("Pass")
else:
    print("Fail")

For Loop

for i in range(1, 6):
    print(i)

While Loop

i = 1

while i <= 5:
    print(i)
    i = i + 1

Python Functions

A function is a reusable block of code that performs a particular task. 

def add(a, b):
    return a + b

result = add(10, 20)

print(result)
